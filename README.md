# 虾饺｜DSH 个人助手

虾饺是一款基于 DeepSeek Harness（DSH）开发的个人 AI 助手插件。它通过全局侧边栏提供统一入口，把聊天、记忆与任务协作放在一起，帮助使用者接续不同工作区中的工作，减少重复交代背景的负担。

> **项目阶段**：开发与验证阶段。
> 这个仓库用于说明项目定位、功能进展和交互思路，**不提供完整源码、可安装的发布包或公开在线演示**。
> 它还不是一个完整的开源产品，暂时也没有源码许可证。

## 它现在有什么

### 已有基础

- **全局侧边栏**：不管当前在哪个工作区，入口都在同一个地方。
- **聊天**：在面板里直接对话，不用切窗口。
- **记忆**：跨会话保留与当前工作相关的上下文，重启之后还能接上。

### 开发中的能力：跨工作区会话协作

这些能力正在开发集成中。目标是让她能替你盯着别的会话，而不是只在自己那一格里说话：

- 跨工作区找到某个会话（按标题、目录、工作区或 id 片段筛选）
- 分页读取会话最近的内容，可以往前翻
- 查看会话当前是运行中还是空闲
- 新建会话、往已有会话续话、停止正在跑的会话
- 订阅会话的进展与终态通知（跑完、卡住、等人回答时告诉你）

访问走 DSH 宿主提供的会话接口，访问范围由一道授权门控制，不靠读取会话文件来绕过边界。

> 状态：这部分属于开发集成，尚未在真实宿主上完成完整工作流验收。

## 交互示例

下面三个场景是**交互示例，非实际测试记录**，用来说明她打算怎么配合你。

### 示例一：接着处理之前的会话

- **你**：找到之前讨论页面设计的会话，帮我接着处理。
- **她**：先跨工作区找到那个会话，读出最近几轮，把结论用两三句话复述给你，再问要不要接着往下推。

### 示例二：查看任务进度

- **你**：看看这个任务现在做到哪一步了。
- **她**：查一下会话状态，把在跑的、卡住的、等人拍板的分开说；卡住的直接说卡在哪一步。

### 示例三：订阅完成通知

- **你**：这个任务完成后告诉我。
- **她**：盯住那个会话。跑完、或者停下来等你的时候，在侧边栏通知你，不用你反复去翻。

## 后续探索（研究设计阶段）

以下都是**计划与研究方向**，不是已实现的功能：

- **多模型按任务分工**：不同任务交给不同模型，各自的长处用在合适的地方。
- **独立分析后交叉检查**：多个模型各自给结论，再互相挑错，最后综合出一份结果。
- **从执行结果里改善协作**：根据执行成败、错误和你的修正，调整任务拆分、工具选择与协作方式。

明确一点：这些是研究设计阶段的设想，**不涉及训练或微调模型**，也**不是已经实现的自动持续改进**。
